# O ABSOLUTO

Prova de conceito do site **O ABSOLUTO**.

## Estrutura prevista

- Introdução.
- 3 Níveis de Consciência.
- 3 Níveis de Consciência e Ortografia.
- Frases numeradas sem limite de três algarismos.
- Página individual para cada frase.
- Conteúdo livre em cada frase.
- Pesquisa global nos capítulos e frases, excluindo o fórum.
- Pesquisa específica na coleção de frases.
- Fórum externo.
- Preparação para edição através de Pages CMS.
- Publicação futura através de GitHub Pages.

## Estado

A versão atual é uma prova de conceito. Os textos e frases são demonstrativos. O GitHub Pages ainda não precisa de ser ativado para continuar o desenvolvimento.
